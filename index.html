Install Our Chrome Extension (TourchSploit)

Follow these quick steps to manually add the extension to Google Chrome.

Download Extension (.zip) Requires manual developer mode installation

Installation Instructions

1
Extract the ZIP: Download the file above, right-click the file, and select Extract All (or Unzip) to unpack it into a normal folder.
2
Open Extensions Page: Open a new tab in Google Chrome and go to chrome://extensions/
3
Enable Developer Mode: In the top-right corner of the extensions page, switch the Developer mode toggle to ON.
4
Load the Folder: Click the Load unpacked button in the top-left corner.
5
Select Directory: Select the extracted folder (the one containing the manifest.json file). Do not select the ZIP file itself.
